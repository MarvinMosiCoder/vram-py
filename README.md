# VRAM Admin

FastAPI and PostgreSQL admin application ported from VRAM Laravel, with an
ongoing migration from React/Vite (`frontend/`) to Next.js (`frontend-next/`).

New frontend work targets `frontend-next/`. Login, the shared admin shell, role themes, and dashboard are
present; the remaining module screens still live in the Vite frontend. See
[frontend migration status](docs/vram/frontend.md#migration-status).

Start with [admin documentation](docs/vram/README.md).
For installation and local development, follow [operations](docs/vram/operations.md).
