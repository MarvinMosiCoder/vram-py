# API Reference

Base URL: `http://localhost:8000`

Interactive, always-up-to-date docs (generated by FastAPI from the code)
are available at `http://localhost:8000/docs` while the backend is
running — this file is a human-readable companion to that.

Routes are documented per feature area under [api/](api/), mirroring how
`backend/app/api/` is split into one file per router:

| Feature | Routes | Docs | Backend file |
|---|---|---|---|
| Auth | `POST /register`, `POST /login`, `POST /logout`, `GET /me` | [api/auth.md](api/auth.md) | `api/auth.py` |
| Dashboard | `GET /dashboard` | [api/dashboard.md](api/dashboard.md) | `api/dashboard.py` |
| Sidebar | `GET /sidebar` | [api/sidebar.md](api/sidebar.md) | `api/sidebar.py` |
| Admin | `GET /admin/users` | [api/admin.md](api/admin.md) | `api/admin.py` |
| Editor | `GET /editor/content` | [api/editor.md](api/editor.md) | `api/editor.py` |

See [ARCHITECTURE.md](ARCHITECTURE.md) for how the auth/RBAC dependency
chain behind these routes is wired together, and why the routes and docs
are both split this way.

## Authentication

This section applies to every route above, so it lives here instead of
being repeated five times.

All routes except `POST /register`, `POST /login`, `/docs`, `/redoc`, and
`/openapi.json` require a JWT, obtained from `POST /login`, sent as:

```
Authorization: Bearer <token>
```

Tokens expire 60 minutes after issue (`ACCESS_TOKEN_EXPIRE_MINUTES` in
`backend/app/core/auth.py`). There is no refresh endpoint — an expired token
means logging in again.

A request with a missing, invalid, expired, or revoked (see
[api/auth.md](api/auth.md)'s `POST /logout`) token gets:

```json
// 401 Unauthorized
{ "detail": "Not authenticated" }        // header missing entirely
{ "detail": "Could not validate credentials" }  // header present but invalid
```

A request from a correctly authenticated user whose role isn't allowed
for that route gets:

```json
// 403 Forbidden
{ "detail": "Requires one of these role ids: 1" }
```

Roles are identified by `adm_roles.id`, not by name — see
[ARCHITECTURE.md](ARCHITECTURE.md)'s RBAC model for why.
